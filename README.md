# 🌌 Infinite-Number-Idle

A monumental, multi-layered incremental (idle) game designed to scale numbers into absolute infinity. The project utilizes a highly modular system, blending multiple programming languages and robust data structures for maximum computation performance.

---

## 🛠️ System Architecture

The project is strictly separated into distinct modules to maintain a clean development workflow:

* **`📁 app/`** – Core game engine. Features Python for the central loop (`core/`), JavaScript for client-side mathematical scaling (`logic/`), and a cyberpunk-themed HTML/CSS interface (`ui/`).
* **`📁 scripts/`** – Automation toolkit. Contains testing bots (`automation/`), command-line compilation tools (`build/`), and system initialization scripts (`system/`).
* **`📁 data/`** – Data persistence layer. Powered by an SQLite relational database (`database/`) for local saves, alongside automated backup systems (`backups/`).
* **`📁 notebooks/`** – Mathematical simulations and balancing sheets within a Jupyter environment, used to calibrate infinite growth and prestige multipliers.
* **`📁 config/`** – Local and server configurations, keybindings, and environment variables.
* **`📁 tests/`** – Unit and stress testing suites dedicated to preventing numerical overflow issues.

---

## 🚀 Planned Features

1. **Infinite Scaling:** The mathematical engine bypasses standard hardware limits, utilizing custom Go and C++ modules to process massive numeric values.
2. **High-Performance Architecture:** Offline progress is calculated instantly via an optimized C++ module, while active gameplay runs smoothly on JS/Python.
3. **Multi-Tier Prestige:** A complex soft-reset system where progress can be sacrificed in exchange for permanent global multipliers and unlockable perks.

---

## 💻 Development Environment

To contribute to this project, the following Visual Studio Code extensions are required:
* **Jupyter** – For running mathematical simulations.
* **SQLite Viewer** – For visual inspection of local databases.
* **Go & C/C++** – For editing high-performance backend modules.
